StudyMate AI 📚

An Alexa+-inspired study assistant that helps students learn smarter.

StudyMate AI is a mobile-friendly study assistant prototype designed to help students understand academic topics in simple language, create study notes, and plan their exam preparation.

✨ Features

- Ask StudyMate: Get sample answers to study questions in simple, student-friendly language.
- Simple Notes: Generate demo study notes that make topics easier to revise.
- Study Planner: Create a sample study plan to organize subjects and revision time.
- Mobile-Friendly Design: Use the interface on a phone, tablet, or desktop.
- Student-Focused Experience: Designed to make exam preparation more organized and accessible.

🎯 Problem

Students often struggle to understand complex topics, prepare short revision notes, and manage their time before exams. StudyMate AI brings these study tools together in one simple interface.

💡 Solution

StudyMate AI provides a single place for students to explore study questions, review simplified notes, and organize their preparation through a study planner.

The project demonstrates an Alexa+-inspired conversational study experience using a prototype interface.

«Prototype notice: This version uses predefined demo/sample responses. It does not currently provide live AI-generated answers or claim official Alexa+ integration.»

🚀 Run Locally

1. Install "Node.js" (https://nodejs.org/) if it is required by the project's dependencies.

2. Clone this repository:
   
   git clone https://github.com/afreen3003/Studymate_ai.git
cd Studymate_ai

3. Install dependencies:
   
   npm install

4. Check the "scripts" section in "package.json" and run the available development command. For example, if the project defines a "dev" script:
   
   npm run dev

5. Open the local URL displayed in the terminal.

Note: The exact run command depends on the scripts defined in "package.json".
